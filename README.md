# Minecraft beta mining cooldown fix

The goal of this mod is to fix the hardcoded delay when mining blocks sequentially. This 5-tick delay occurs whenever you hold down the left mouse key while mining. However, if you physically click a block just after the previous break, this cooldown is bypassed. Because clicking every block is not very convenient, this is where this mod comes in. It currently supports both vanilla Beta 1.7.3 and the [Back2Beta (1.7.9)](https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/3150500-back2beta-1-7-9-mod-for-beta-1-7-3) port.

## Installation

- Insert os.class and kx.class files into the minecraft.jar file.
- You may need to delete the "META-INF" folder located inside the "minecraft.jar" if game crashes.
